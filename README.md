# 肉店大师 (Roll)

一个现代、有趣的决策辅助工具，旨在用优雅的交互和清爽的视觉设计，帮你快速摆脱选择困难。

这个项目源于一个简单的个人安卓应用，经过多次迭代，最终演变为一个功能丰富、体验流畅的现代化渐进式网络应用 (PWA)。

![应用截图](https://raw.githubusercontent.com/CuteRem/roll-pwa/refs/heads/main/screenshot.jpg)  

## ✨ 功能特色

- **快速决策引擎**: 无需保存，即用即走，满足你最直接的决策需求。
  - **数字滚动**: 在指定范围内生成随机数，通过“老虎机”动画呈现结果。
  - **是非判断**: 快速获得“是”或“否”的判断，伴有清脆的对错图标动画。
  - **抛硬币**: 体验一枚精心设计的2D动画硬币带来的经典对决，正反面清晰可辨。
  - **自定义滚动**: 输入你的所有选项，让“老虎机”为你决定最终选择。
- **老虎机式滚动器 (Slot Machine)**: 告别传统转盘因选项过多而难以阅读的弊病。全新的垂直滚动器即使在选项极多时也能保证内容的清晰可读，并配有极富满足感的减速和锁定动画。
- **PWA 支持**: 可以将应用“安装”到你的桌面或手机主屏幕，像原生 App 一样使用，并支持离线访问和新版本自动更新提示。
- **明暗主题切换**: 内置对系统主题的自适应，并可手动切换，保护你的双眼。
- **响应式设计**: 在桌面、平板和移动设备上均有良好且一致的体验。

## 🚀 技术栈

- **前端框架**: React
- **开发语言**: TypeScript
- **UI 组件库**: Chakra UI
- **构建工具**: Vite
- **动画**: Framer Motion
- **PWA**: Vite PWA Plugin

## 🛠️ 本地开发

1. **克隆仓库**
   ```bash
   git clone https://github.com/CuteRem/roll-pwa.git
   cd roll-pwa
   ```

2. **安装依赖**
   推荐node版本18+
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```
   应用将在 `http://localhost:5173` (或类似地址) 启动，并已配置为支持局域网访问。

4. **构建生产版本**
   ```bash
   npm run build
   ```

5. **预览生产版本**
   ```bash
   npm run preview
   ```
